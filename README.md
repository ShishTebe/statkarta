# СтатКарта

Помощник следователя по заполнению статистических карточек первичного учета преступлений
(формы 1, 1.1, 2, 2.1, 3, 4, 5, 6, ИПК и карта на преступление с участием иностранных граждан).
Программа берет сведения из постановления о возбуждении уголовного дела и ответов
пользователя. По каждому событию дела она составляет пакет карточек: показывает реквизиты
каждой – какие коды вписывать и откуда они взяты, печатную копию бланка и заполненный файл
Word или Excel. Одну карточку без дела можно заполнить и распечатать в быстром режиме.

Работает без сервера и без сети. Сведения дела и профиль органа хранятся только на компьютере
пользователя и никуда не передаются – ни на сайт программы, ни разработчику, ни в облако. На диск
сведения дела записываются только зашифрованными под паролем.

Программа – подсказка, а не карточка: коды и сведения проверяет и подписывает лицо,
составляющее карточку.

## Как открыть (на компьютере)

Установка не нужна, права администратора – тоже. Подходят браузеры Chrome, Edge, Яндекс.Браузер,
Brave и Safari на macOS и Windows.

**Способ 1. Файл без интернета.** Скачайте `statkarta-offline.html` со страницы
[выпусков](https://github.com/ShishTebe/statkarta/releases/latest) (или перенесите его на
флешке) и откройте двойным щелчком. Новая версия – новый файл вместо старого.
Сохраненные дела и профиль органа при этом не теряются: они записаны на этом компьютере, во
внутреннее хранилище браузера (дела – зашифрованными под паролем), и в интернет не передаются.
На другом компьютере или в другом браузере их не будет – для переноса дело сохраняется в
зашифрованный файл.

**Способ 2. Адрес в браузере.** Откройте https://shishtebe.github.io/statkarta/. С этого адреса
загружается только сама программа; сведения дел и профиль органа на сайт не отправляются и
хранятся так же, как в способе 1, – на этом компьютере. После первого открытия программа
работает и без сети. В Chrome, Edge и Яндекс.Браузере ее можно установить
как приложение: значок установки в адресной строке или меню → «Установить СтатКарта».

Проверка обновлений – только по кнопке «Проверить обновления». Раз в полгода (после 01.01 и
01.07) программа напоминает сверить формы и справочники по чек-листу.

## Что внутри

| Папка | Назначение |
|---|---|
| `data/forms/2026/` | Формы карточек ред. 2026: реквизиты, типы, коды, кто заполняет |
| `data/classifiers/2026/` | Справочники № 1–12, 14–16 |
| `data/uk/2026/` | Статьи УК РФ с категорией тяжести; перечни статей (указание от 28.07.2025 № 147) |
| `data/legal/2026/` | Реестр нормативных актов, разъяснения с привязкой к реквизитам, чек-лист актуальности |
| `data/rules/2026/` | Факты, вопросы опросника, сопоставление с реквизитами, проверки, правила извлечения из документов |
| `data/events/2026/` | События дела и состав пакета карточек по каждому событию |
| `data/blanks/2026/` | Бланки карточек (без образцов заполнения) |
| `data/layout/2026/` | Карты раскладки: куда в бланке вписывается каждый реквизит |
| `data/schema/` | JSON-схемы пакетов |
| `src/` | Ядро (без внешних библиотек) и интерфейс |
| `tests/` | Автотесты; только вымышленные образцы |
| `scripts/` | Импорт, генерация правил, проверка данных, аудит публичности, сборка |
| `docs/` | Устройство приложения, инструкции сопровождающему, журнал изменений |

Справочник № 17 (реестр подразделений) в репозиторий не входит.

## Регион

Регион выбирается в профиле органа: от него зависят местные коды следственных подразделений,
их строка в бланках и ОКАТО. Пакет Камчатского края встроен, пакеты остальных регионов
загружаются с адреса публикации или из файла и хранятся на компьютере. Если у региона нет
местных кодов, их можно предложить из программы. Подробно – `docs/REGIONS.md`.

## Замечания и предложения

Кнопка **«Замечание»** в программе: место в программе подставляется само, текст проверяется на
сведения уголовных дел, замечания копятся на компьютере и выгружаются партией письмом,
файлом, текстом или заявкой на GitHub. Там же – ревизия правил (отметки «верно / неверно /
уточнить» по каждому правилу) и «Что нового» после обновления. Подробно – `docs/FEEDBACK.md`.
Сведения реальных дел не присылайте.

`docs/HOW_TO_UPDATE_CLASSIFIERS.md`. Изменения – `docs/CHANGELOG.md`.

## Правила проекта

- Предметные данные берутся только из официальных источников; у каждого правила есть ссылка на источник.
- Данные уголовных дел в репозиторий не попадают, даже в тестах: образцы только вымышленные.
- Ядро детерминированное, без языковых моделей и сетевых запросов.
- Типографика: буква «е» вместо «ё», среднее тире, даты ДД.ММ.ГГГГ.
