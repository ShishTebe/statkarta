# Региональные пакеты

С версии 0.10.0 программа не привязана к одному региону. Общие данные (формы, справочники,
правила) одинаковы для всех; от региона зависят три вещи:

1. **Местные коды следственных подразделений** в реквизитах «уголовное дело расследовано /
   находится в производстве / решение принято»: ф. 1 р. 40, ф. 1.1 р. 33, ф. 2 р. 54,
   ф. 2.1 р. 26, ф. 3 р. 15, ф. 4 р. 33, ф. 5 р. 21. Информационные центры печатают их в своих
   бланках после «следственных органов СК РФ (0001)» строкой «в т.ч. …».
2. **Строка этих кодов в бланке.** Бланки в `data/blanks/2026` – бланки информационного центра
   Камчатского края. Для другого региона строка камчатских кодов при заполнении заменяется
   строкой его пакета, а если ее нет – убирается.
3. **ОКАТО** места совершения преступления (ф. 1 р. 19.1, ф. 2 р. 28.1, ф. 5 р. 18.3).

## Для пользователя

Профиль органа → «Регион»: выберите регион. Пакет Камчатского края встроен в программу; пакет
другого региона загружается кнопкой «Загрузить пакет с адреса публикации» или «Загрузить из
файла» (для компьютера без интернета: «Файл пакета для переноса» на другом компьютере, затем файл
переносится). Пакет – открытые справочные данные и хранится на этом компьютере; сведения дел в
него не входят и никуда не передаются.

Если у вашего региона местных кодов еще нет – «Предложить местные коды своего региона»: коды и
строку перепишите из бланков своего информационного центра. Предложение уходит в журнале
замечаний (письмом или файлом).

## Для сопровождающего

Сведения региона – в `scripts/import/regions-2026.json`, раздел `regions`:

```json
"08": { "status": "verified", "unit_codes": [{ "code": "0018", "value": "в т.ч. …" }],
        "blank_line": { "*": "в т.ч. … (0018), …" }, "sources": ["бланк ИЦ …, дата"] }
```

- `unit_codes` – код из 4 цифр и наименование, как в бланке; `forms_value` – другое наименование
  для отдельной формы (у Камчатского края в ф. 3 – «СО по ОВД»).
- `blank_line` – строка для бланков; ключ `*` – для всех форм, ключ формы – для отдельной.
- Вносится только по бланкам или письму информационного центра региона.

Предложения из программы: `node scripts/feedback/intake.mjs <файл партии> --regions-json` – готовый
раздел `regions`; сверить с источником и перенести. Затем:

```bash
python3 scripts/import/build_regions.py
```

```bash
python3 scripts/normalize_typography.py
```

```bash
npm run manifest
```

```bash
node scripts/validate-data.mjs --warnings
```

ОКАТО всех регионов собирается из CSV Росстата («Карточки/ОКАТО/»); без него сценарий сохраняет
ОКАТО из уже собранных пакетов. Реквизиты-цели и строки камчатского бланка по формам заданы в том
же файле (`targets`, `blank_fragments`): при смене бланков их нужно сверить заново.
